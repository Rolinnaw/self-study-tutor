# Course setup and source coverage

Use this procedure once when starting a subject and update it whenever the learner adds materials.

## Intake

Capture only information that affects teaching:

- subject name and level;
- desired outcome: pass, high grade, conceptual mastery, project ability, professional application, or a combination;
- assessments, due dates, permitted tools, and expected answer language;
- learner background, language needs, known gaps, and teaching preferences;
- declared source categories and the files belonging to each category.

Ask only for material missing from a category the learner says exists. A category may legitimately be absent.

## Source roles

Confirm the role and precedence of sources. Suggested default:

1. official syllabus, assessment instructions, rubrics, and lecturer corrections;
2. official lectures for examinable concepts and terminology;
3. official workshops/labs and solutions for expected procedures and application;
4. assigned textbook for foundations, derivations, and fuller explanations;
5. tutoring-class or third-party materials for alternative explanations and extra practice;
6. tutor-created examples and clearly labelled extensions.

All relevant sources still contribute even when precedence differs. Higher precedence resolves scope or factual conflicts; it does not permit ignoring useful lower-precedence explanations or practice.

## Inventory and coverage map

Inspect every supplied file sufficiently to identify its unit, headings, learning objectives, examples, exercises, solutions, figures, and assessment relevance. For visual documents, do not rely only on extracted text when layout, diagrams, tables, or notation carry meaning.

Build a map with topic, prerequisites, coverage by each supplied source category, assessment relevance, available practice, and learning status. Use the map to catch omissions and connect explanations across sources. Do not dump the entire map on the learner unless it helps planning.

## Conflict and gap handling

- Identify conflicting locations briefly, state which source controls, and explain why.
- Preserve alternative terminology likely to appear in exams.
- Flag suspected typos rather than silently repairing them.
- If a prerequisite is absent from course materials, teach the minimum bridge and label it as an extension.
- If a declared source has not been provided or cannot be read, state the resulting coverage gap.

## Persistent course state

When the environment permits and the learner wants continuity, maintain a small course profile and progress record beside the learning project or in an agreed workspace. Keep source files unchanged. Record source inventory, preferences, coverage status, misconceptions, and next task without storing unnecessary personal information.
